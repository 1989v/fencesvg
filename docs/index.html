fencesvg

Type mermaid, get SVG

Five diagram types, no runtime dependencies, and no canvas — the output is plain SVG whose every colour and radius is a var(--fs-…) reference. Switch the look below and the diagram follows without being redrawn: it wears your palette instead of bringing its own.

const { svg, caption, warnings } = renderDiagram(source);

   :root { --fs-ink: …; --fs-line: …; --fs-node-fill: …; --fs-accent: …; }
